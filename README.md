# Klebanoff et al.  Analysis code repository

Contains the following code:

scRNAseq_integrated_object_analysis.R:
  Analysis of scRNAseq/scTCRseq/CITEseq data from the seroconverting donor and the 5-donor latently infected cohort

BulkTCRseq_Fig-4_analysis.R:
  Analysis of the bulk TCRseq data collected for Figure 4 of the manuscript

FordES_1__parse_contigs_121325.py and FordES_2__tcrdistgpu_klebanoff_2026.py:
  From our collaborator (Emily S. Ford), code used to identity TCRdist clusters in Figure 5 of the manuscript


Associated Seurat objects used in scRNAseq_integrated_object_analysis.R can be found on GEO. Raw sequencing data for the entire project can be found on dbGaP.
